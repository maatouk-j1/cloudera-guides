## Cloudera Runtime

Cloudera Runtime is the core open-source software distribution within Cloudera Base on premises. Cloudera Runtime includes approximately 50 open-source projects that comprise the core distribution of data management tools within Cloudera Platform.

For more information review Cloudera Runtime Release notes:

[Cloudera Runtime 7.3.2 - What's New](https://docs.cloudera.com/cdp-private-cloud-base/7.3.2/private-release-notes/topics/rt-whats-new.html)

Please review runtime cluster hosts and role assignments:

[Runtime Cluster Hosts and Role Assignments](https://docs.cloudera.com/cdp-private-cloud-base/7.3.2/cdp-private-cloud-base-installation/topics/cdpdc-runtime-cluster-hosts-role-assignments.html)
