## Cloudera on premises (PvC) Data Services (DS) Installation

Cloudera Data Services on premises lets you deploy and use the Cloudera Data Warehouse (CDW), Cloudera AI (CAI) and Cloudera Data Engineering (CDE) Data Services.

This section summarizes Cloudera Data Services on premises v1.5.5 installation through Embedded Container Service on Cloudera Base on premises 7.3.2.

A Cloudera Data Services on premises deployment includes an Environment, a Data Lake, the Management Console, and Data Services (Data Warehouse, Machine Learning, Data Engineering). Other tools and utilities include Replication Manager, Data Recovery Service, CDP CLI, and monitoring using Grafana.

To deploy Cloudera Data Services on premises you need a Cloudera Base on premises cluster, along with container-based clusters that run the Data Services. You can either use a dedicated **RedHat OpenShift container cluster (OCP)** or deploy an **Embedded Container Service (ECS)** container cluster.

<Banner type="info">
This guide takes the **ECS** path throughout. OCP is named here for completeness only - none of the pages that follow cover an OpenShift deployment.
</Banner>

The Cloudera on premises deployment process involves configuring Management Console, registering an environment by providing details of the Data Lake configured on the Base cluster, and then creating the workloads.

Platform Managers and Administrators can rapidly provision and deploy the data services through the Management Console, and easily scale them up or down as required.

## What the Base cluster provides

Cloudera Base on premises provides the following components and services that are used by Cloudera Data Services on premises:

- SDX Data Lake cluster for security, metadata, and governance
- HDFS and Ozone for storage
- Powerful and open-source Cloudera Runtime services such as Ranger, Atlas, Hive Metastore (HMS), etc.
- Networking infrastructure that supports network traffic between storage and compute environments.

Every one of these was stood up over the previous chapter - the [Data Lake](/installations/cdp-7-3-2/on-premises/base/data-lake) carries Ranger, Atlas, HMS, HDFS and Ozone, and the [preliminary work](/installations/cdp-7-3-2/post-os-work) laid down the DNS and network foundation the container cluster now depends on.
